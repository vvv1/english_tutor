1. Conditionals: условие и следствие

Чем дальше ситуация от реальности, тем дальше назад сдвигается время глагола. Про будущее в if-части говорим настоящим временем, без will.

Пять типов условных предложений
ТипIf-частьГлавная частьЗначение
ZeroPresent SimplePresent Simpleвсегда так, правило
FirstPresent Simplewill + Vреально в будущем
SecondPast Simplewould + Vвоображаемо сейчас
Thirdhad + V3would have + V3иначе в прошлом
Mixedhad + V3would + Vпрошлое → сейчас

Порядок частей одинаков для всех типов. Если условие стоит первым, после него ставится запятая. Если первой идёт главная часть, запятая не нужна: We'll roll back if the build fails.

0

Zero conditional: всегда так

Правило или факт, который срабатывает каждый раз. Обе части — в Present Simple.

ФормулаIf + Present, Present

Так описывают поведение системы, которое не зависит от конкретного дня: документация, README, ответы поддержки. If можно заменить на when или whenever — смысл не изменится.

  • If the cache is empty, the app queries the database.
  • If a request takes longer than 30 seconds, the gateway returns 504.
  • When the disk is full, the service stops writing logs.

В инструкциях главная часть часто повелительная: If the build fails, check the logs.

Когда нужен не нулевой, а первый тип

Нулевой тип — про то, что происходит каждый раз. Если речь об одной конкретной ситуации в будущем, нужен первый тип с will: If the cache is empty after tonight's deploy, we'll warm it up manually.

Проверка: подходит ли по-русски «всякий раз, когда»? Если да — нулевой тип.

1

First conditional: реальное будущее

Конкретная ситуация, которая вполне может случиться. Будущее — только в главной части.

ФормулаIf + Present, will + V

По-русски «если сборка упадёт, мы откатим релиз» — будущее время в обеих частях. По-английски в условии остаётся Present Simple, а will стоит только в следствии. Так обсуждают планы и риски на стендапе: что сделаем, если тесты упадут или релиз сдвинется.

  • If the build fails, we'll roll back the release.
  • If the tests pass, I'll merge the PR tonight.
  • We'll miss the deadline if the API isn't ready by Friday.

Типичные ошибки

Ошибка Будущее в условии

If the tests will pass, we will merge the PR.

Почему

Калька с русского «если тесты пройдут». В if-части первого типа — Present Simple, will — только в главной части. То же правило действует после when, as soon as, before, after, until: When the release is out, we'll update the docs.

Верно Present Simple в условии

If the tests pass, we'll merge the PR.

Ошибка Двойное отрицание с unless

Unless you don't have access, ask the admin.

Почему

Unless уже означает if not — «если не». С ещё одним отрицанием фраза говорит обратное: «если у вас есть доступ, спросите администратора».

Верно Unless без второго not

Unless you have access, ask the admin.

Когда will после if всё-таки уместен

If в значении «ли». В косвенном вопросе if — не условие, а «ли», и будущее время в нём обычное: I'm not sure if the fix will work. — «Не уверен, сработает ли исправление». Проверка простая: если по-русски получается «ли», will нужен.

Готовность или вежливая просьба. Will означает «согласны ли вы»: If you will wait a moment, I'll check the logs.

Следствие самого условия. Результат наступит позже решения: If it will save us a week, let's buy the license. — «если это (в итоге) сэкономит нам неделю».

Во всех остальных случаях действует правило из формулы: в условии про будущее — Present Simple.

Подробности: when или if, формальный стиль — First conditional

When или if. When — уверены, что событие произойдёт: When the release is out… If — может и не произойти: If the release slips…

Формальная инверсия. В официальных письмах и документации if иногда опускают и начинают с should: Should you have any questions, contact support.

2

Second conditional: воображаемое сейчас

Ситуация нереальна или маловероятна сейчас. Обе части делают шаг назад: Present → Past, will → would.

ФормулаIf + Past, would + V

Past здесь означает не прошлое, а дистанцию от реальности: данных у нас мало, но представим, что больше. Так формулируют гипотезы и советы — что было бы при других ресурсах или на месте коллеги.

  • If we had more data, the model would be more accurate.
  • If I were you, I'd refactor this module.
  • If the service didn't depend on the legacy API, we could deploy it daily.

Типичные ошибки

Ошибка Would в обеих частях

If I would have admin rights, I would fix it myself.

Почему

По-русски «бы» стоит в обеих частях: «если бы у меня были права, я бы исправил». В английском would — только в главной части, а условие второго типа — в Past Simple.

Верно Past Simple в условии

If I had admin rights, I'd fix it myself.

Ошибка Совет через «на твоём месте»

If I am you, I would refactor this module.

Почему

Оказаться на месте собеседника нельзя — это воображаемая ситуация, второй тип. Устойчивая форма — were для всех лиц. If I was you встречается в разговорной речи, но were звучит нейтрально в любом контексте.

Верно If I were you

If I were you, I'd refactor this module.

Первый или второй тип — решает говорящий

Одна и та же ситуация может быть реальной или маловероятной — всё зависит от того, как вы её оцениваете. If we get the budget, we'll hire two engineers. — бюджет вполне могут дать. If we got the budget, we'd hire two engineers. — шансы невелики.

Подробности: could и might вместо would — Second conditional

If we had more time, we could add integration tests — «смогли бы». If we had more time, we might add them — «возможно, добавили бы».

3

Third conditional: упущенное прошлое

Прошлое уже сложилось иначе. Ещё шаг назад: Past → Past Perfect, would → would have + V3.

ФормулаIf + had + V3, would have + V3

Язык разборов инцидентов (postmortem): что пошло бы иначе, если бы команда поступила по-другому. Утвердительное условие означает, что в реальности действия не было: had tested — миграцию не протестировали.

  • If we had tested the migration, we wouldn't have lost the data.
  • If the alert had fired, the on-call engineer would have reacted in minutes.
  • We could have avoided the outage if we had checked the config.

Типичная ошибка

Ошибка Would have в условии

If we would have checked the logs, we would have found the bug.

Почему

В третьем типе условие — had + V3. Форма if … would have встречается в разговорной американской речи, но в письменной работе и в постмортеме её считают ошибкой.

Верно Past Perfect в условии

If we had checked the logs, we'd have found the bug.

Подробности: сокращение 'd, формальный стиль — Third conditional

Сокращение 'd. I'd — это I would или I had. В If I'd known about the outage, I'd have told you первое 'd — had (сразу после if), второе — would (перед have + V3).

Формальная инверсия. В официальных письмах if опускают и начинают с had: Had we known about the issue, we would have notified customers.

M

Mixed conditional: прошлое и настоящее

Условие и следствие относятся к разному времени, и каждая часть берёт форму своего типа.

Прошлое → сейчасIf + had + V3, would + V

Самый частый вариант. Условие в прошлом, как в третьем типе; следствие в настоящем, как во втором. Так объясняют, почему система сейчас в таком состоянии.

  • If we had fixed the bug yesterday, the release would be ready now.
  • If we hadn't skipped the code review, we wouldn't be debugging this in production.

Сейчас → прошлоеIf + Past, would have + V3

Обратное направление: воображаемое постоянное положение дел (второй тип) объясняет прошлый результат (третий тип).

  • If we had proper monitoring, we would have noticed the outage earlier.
  • If I weren't on call this week, I would have joined the offsite.

В первом примере had — Past Simple глагола have: нормального мониторинга нет и сейчас. Это не Past Perfect.

Типичная ошибка

Ошибка Следствие ушло в прошлое

If we had fixed the bug yesterday, the release would have been ready now.

Почему

Третий тип по инерции: обе части отправлены в прошлое. Но now говорит, что следствие — в настоящем, поэтому главная часть возвращается к would + V.

Верно Would + V для настоящего

If we had fixed the bug yesterday, the release would be ready now.

Результат

Балл засчитан только за точный выбор вариантов. Под каждым вопросом — правильные варианты и объяснение.

  1. First conditional

    Вопрос 1 · Один ответ If the deployment ___, we'll roll back.

    Реальная ситуация в будущем — первый тип. Будущее показывает will в главной части, а в условии — Present Simple: fails.

  2. Second conditional

    Вопрос 2 · Один ответ GPU не хватает. Как сказать «если бы у нас было больше GPU, обучение шло бы быстрее»? If we ___ more GPUs, training ___ faster.

    Воображаемое настоящее — второй тип: обе части на шаг назад. Условие — Past Simple (had), следствие — would + V. Would в условии и will в следствии здесь не подходят.

  3. Все типы

    Вопрос 3 · Несколько ответов Какие предложения грамматически верны?

    Верны совет через If I were you, правило нулевого типа и unless без второго отрицания. В варианте про знание нужно If we had known, а в варианте про помощь — If you need help: это условие о будущем, а не просьба о готовности.

  4. Third conditional

    Вопрос 4 · Один ответ If we had backed up the database, we wouldn't have lost the data. Что произошло на самом деле?

    Третий тип описывает прошлое, которое сложилось иначе. Утвердительное условие означает, что в реальности действия не было, отрицательное следствие — что результат наступил: копии нет, данные потеряны.

  5. Mixed conditional

    Вопрос 5 · Один ответ Год назад вы отказались от оффера в Лондоне. If I had accepted that offer, I ___ in London now.

    Смешанный тип: условие в прошлом (had accepted), следствие сейчас — на это указывает now. Главная часть возвращается к would + V; длительная форма would be living подчёркивает текущее состояние. Would have lived отнесло бы следствие в прошлое.

  6. Third conditional

    Вопрос 6 · Один ответ If I'd known about the outage, I'd have told you. Что означают первое и второе 'd?

    Третий тип: If I had known…, I would have told you. Сразу после if сокращение почти всегда означает had; перед have + V3 — would.

  7. First conditional

    Вопрос 7 · Один ответ Релиз точно выходит в пятницу. Какое начало точнее передаёт уверенность? ___ the release is out, we'll update the docs.

    When — событие точно произойдёт, вопрос только во времени. If грамматически возможен, но добавляет сомнение: релиз может и не выйти. Unless меняет смысл на «если не», in case — «на случай, если».

  8. First conditional

    Вопрос 8 · Несколько ответов В каких предложениях will после if уместен?

    В первом варианте if значит «ли» — это косвенный вопрос, а не условие. В варианте с ожиданием will выражает готовность собеседника. Варианты про падение сервера и сдвиг релиза — обычные условия о будущем: If the server crashes…, If the release slips…

  9. Second conditional

    Вопрос 9 · Несколько ответов Какие предложения описывают воображаемое настоящее?

    Второй тип — Past Simple в условии и would + V: права администратора и участие в команде воображаемые. Вариант с get — реальная возможность в будущем (первый тип), с had had — упущенное прошлое (третий тип).
